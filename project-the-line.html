About the Project

WHAT IS
THIS?

The Line Studio is a globally renowned animation studio based in East London — responsible for visually striking commercial work for Riot Games, Marvel, Blizzard, Mercedes-Benz, Gucci, Gorillaz, and Honda. Their website won Awwwards Site of the Month — one of the most prestigious recognitions in the global web design industry.

This project is a pixel-perfect, full-stack rebuild of that award-winning website — reconstructed entirely from scratch. Every scroll animation, every motion transition, every typographic detail, every interactive system was reverse-engineered, understood, and rebuilt by hand.

Rebuilding an Awwwards Site of the Month is one of the most demanding self-imposed challenges a frontend developer can take on. These are interactive experiences built by specialist agencies with dedicated teams working over months. Building this forced a deep, granular understanding of how world-class frontend teams think.

The result demonstrates mastery of modern frontend architecture, advanced animation systems, and premium UI/UX implementation — with a production-grade Next.js 15 application that matches the visual fidelity and interaction depth of the original.

Project Details
  • Type: Awwwards Site of the Month Clone
  • Original: The Line Studio — East London Animation Studio
  • Framework: Next.js 15 (App Router)
  • Language: TypeScript — full type safety
  • Status: Complete · 16 commits · Live on GitHub Pages
Key Systems Built
  • Scroll-driven 3D multi-layer hero animation
  • Physics-based custom cursor (spring interpolation)
  • Real-time navbar theme switching via IntersectionObserver
  • Lenis smooth scroll at root layout level
  • Sticky layered scroll choreography (Hero, Cards, Footer)
  • Variable font loaded via Next.js localFont API
  • FlickerText letter-by-letter glitch animation
  • Dynamic [slug] routing for all nav links
  • Desktop/mobile component bifurcation with null-safe hydration
  • Red zone (News, Contact, Footer) with peeling reveal
Design System
  • 4-colour palette — Void Black, Off White, Flare Red, Cool Gray
  • DenimVF variable font via CSS custom property
  • All sizing in viewport units (vw) — no breakpoints needed
  • Tailwind CSS 4 @theme engine for design tokens

Key Highlights
01
Scroll-Driven 3D Hero
Three independently animated layers — red overlay, SVG wordmark, and HighlightCard — all composited via sticky positioning and useTransform hooks with different motion offsets.
02
Physics Cursor
Spring-interpolated cursor with mass/damping/stiffness parameters giving it characteristic lag and snap behaviour. Renders contextual labels per zone.
03
Real-Time Nav Theming
IntersectionObserver sentinel architecture fires theme callbacks as the user scrolls between dark and light sections — zero scroll event listeners.
04
Lenis Smooth Scroll
Lerp-interpolated scroll at root layout level — wraps the entire app so every component inherits the premium momentum feel automatically.
05
FlickerText Glitch
Letter-by-letter opacity animation sequence on the CTA headline. Simultaneously slides text right and sweeps the underline away in opposite direction.
06
Footer Peel Reveal
Footer sits sticky at z-0 while the Contact section peels away over it using rotate+translate exit animation, revealing the footer as if it was always there.
