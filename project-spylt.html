ABOUT
THE PROJECT

Spylt is a GSAP-powered landing page that demonstrates advanced frontend animation techniques inspired by Awwwards-winning creative studios. Built with Next.js 14 and TypeScript, the project focuses entirely on delivering a premium, cinematic browsing experience through precise animation choreography.

Every section has its own distinct animation system — from scroll-triggered text reveals and parallax image layers to clip-path morphing transitions and staggered entrance animations. The architecture was designed with performance in mind, using GSAP's ScrollTrigger plugin to synchronise all animations to the user's scroll position with scrub-based precision.

The project demonstrates a deep command of GSAP timelines, ScrollTrigger scrubbing, CSS clip-path animation, and Next.js App Router — skills directly applicable to building production-grade creative websites for premium brands.

GitHub Pages

Key Highlights
01
Scroll-Triggered Animation Architecture
Every section uses GSAP ScrollTrigger with scrub-based precision — animations are tied directly to scroll position rather than firing once on enter, creating a cinematic feel where the user controls the pacing.
02
Clip-Path Morphing Transitions
Section transitions use CSS clip-path morphing animated through GSAP — polygon shapes expand and contract as the user scrolls, revealing content beneath with an organic, non-linear feel.
03
Parallax Layering System
Multiple layers move at independent scroll speeds to create depth — foreground, midground and background elements each have their own ScrollTrigger instance with different scrub values.
04
Text Reveal Animations
Headlines split into individual lines and words, each entering from below with staggered timing — a technique inspired by the typographic animation style of top-tier creative agencies.
05
Next.js App Router + TypeScript
Built on Next.js 14 with the App Router and full TypeScript coverage — modern project structure with clean component separation and type-safe animation configurations.
06
16-Commit Staged Development
Built across 16 structured commits — scaffold → design system → scroll engine → section-by-section assembly → deployment — mirroring professional frontend development workflow.
