ABOUT
THE PROJECT

Movie Recommender is a full stack machine learning web application that suggests movies similar to a user's favourite based on content analysis. The project was built to demonstrate the practical application of ML algorithms within a modern web architecture — combining a Python-based recommendation engine with a responsive React frontend.

The core of the system is a content-based filtering model trained on the TMDB 5000 Movie Dataset. Each movie is represented by a combined tag string of its overview, genres, keywords, top cast members, and director. These tags are vectorised using a CountVectorizer and then cosine similarity is computed across the entire dataset, allowing the system to identify and rank the most similar movies for any input in real time.

When a user searches for a movie, the React frontend sends a request to the FastAPI backend, which loads the precomputed similarity matrix from a serialised pickle file and returns the top ten recommendations instantly. Each result is displayed with its official poster fetched dynamically from the TMDB API, creating a visually engaging experience.

The frontend features a live search input that queries the backend as the user types, returning matching titles as suggestions. Results appear in a responsive poster grid with hover effects and smooth transitions. The backend is deployed on Render and the frontend on Vercel, making the full application accessible online without any local setup.

Key Features
01
Content-Based Filtering Engine
Each movie is represented by a unified tag combining overview, genres, keywords, cast, and director. A CountVectorizer converts these into numerical vectors, and cosine similarity ranks every movie in the dataset against the selected input.
02
Live Search with Type-Ahead Suggestions
As the user types, the frontend queries the backend and returns matching movie titles in real time — allowing quick selection without needing to know the exact title spelling.
03
Dynamic Poster Grid via TMDB API
Each of the top ten recommendations is displayed with its official poster image fetched live from the TMDB API, producing a visually rich results layout with hover effects and smooth transitions.
04
FastAPI REST Backend
The recommendation logic is served via a FastAPI endpoint. The precomputed similarity matrix is loaded from a pickle file on startup, keeping response times fast without recomputing on every request.
05
Full Cloud Deployment Pipeline
The backend is deployed on Render and the frontend on Vercel. Environment variables manage API keys and cross-origin resource sharing is configured correctly to allow the two services to communicate in production.
06
ML Model Serialisation with Pickle
The trained cosine similarity matrix and movie metadata are serialised to pickle files during the model-building phase, enabling the backend to load them instantly at runtime without re-training or re-processing the dataset.
Tech Stack
Python
Core language for the ML pipeline — data processing, model building, similarity computation, and API logic.
FastAPI
REST API framework serving movie search and recommendation endpoints — fast, async, and auto-documented.
React.js
Frontend framework powering the live search interface, recommendation grid, and responsive poster layout.
Scikit-learn
CountVectorizer for text vectorisation and cosine similarity for computing movie similarity scores across the dataset.
Pandas / NumPy
Data manipulation and processing of the TMDB 5000 Movie Dataset — cleaning, merging, and feature engineering.
TMDB API
External API integration for fetching official movie poster images displayed with each recommendation result.
Render
Cloud platform hosting the FastAPI backend — deployed directly from the GitHub repository with automatic builds.
Vercel
Frontend hosting with automatic deployments from GitHub — the React app is live globally with zero configuration.
