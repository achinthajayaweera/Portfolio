ABOUT
THE PROJECT

This project was built as part of the Web Design and Development module at IIT — a formal academic assignment requiring a fully functional, multi-page website built from scratch using vanilla HTML, CSS, and JavaScript. The chosen topic was UN Sustainable Development Goal 15: Life on Land, which focuses on protecting, restoring and promoting sustainable use of terrestrial ecosystems.

The site spans multiple interconnected pages — Home, Table, Volunteer, Feedback, Team, and Sitemap — all sharing a consistent design system built with a shared CSS file. Each page was carefully structured with semantic HTML, accessible markup, and a cohesive visual language that communicates the environmental theme throughout.

GSAP animations were integrated into the Table and Sitemap pages to add scroll-driven interactivity, demonstrating real JavaScript animation architecture within an academic deliverable. The project earned a strong result and represents a clean example of structured, modular front-end development.

Tech Stack
HTML5
Semantic multi-page architecture with accessible markup, proper heading hierarchy, and structured content across 6 interconnected pages.
CSS3
Shared stylesheet system across all pages — consistent design tokens, responsive breakpoints, and a cohesive environmental visual theme.
JavaScript
Vanilla JS for DOM manipulation, interactive elements, form handling, and GSAP integration — no frameworks or dependencies beyond the animation library.
GSAP
Scroll-driven animations on the Table and Sitemap pages — timeline sequences and scroll-triggered entrance effects that demonstrate professional animation architecture.
Responsive Design
Fully responsive across desktop, tablet, and mobile — flexible grid layouts, fluid typography, and media queries throughout every page.
GitHub
Version controlled with structured commits and deployed via GitHub Pages. Repo structured with organised asset folders and clean separation of concerns.
