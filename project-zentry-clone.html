ABOUT
THE PROJECT

Zentry is one of the most celebrated websites on Awwwards — known for its cinematic scroll animations, immersive video backgrounds, and buttery-smooth transitions. This clone is a full technical recreation of that experience, built entirely from scratch without lifting a single line from the original source.

The project was an exercise in advanced front-end engineering: implementing scroll-driven clip-path reveals, GSAP ScrollTrigger timelines, and Lenis smooth scroll integration — all within a modern React + TypeScript + Vite stack. Every section, animation and interaction was reconstructed by studying the original's behaviour and rebuilding the mechanics independently.

Special attention was given to matching the typography system, video sequencing, and the signature "tilt on scroll" hero transition that makes Zentry instantly recognisable.

Key Features
01
Scroll-Driven Clip-Path Hero
The hero video expands from a small window to full-screen using a clip-path animation that's precisely tied to scroll position via GSAP ScrollTrigger — matching Zentry's signature entrance effect.
02
Lenis Smooth Scroll Integration
Lenis is wired into the GSAP ticker for frame-perfect smooth scroll. Every section transition feels cinematic and natural, not mechanical.
03
Video Sequencing & Bento Grid
Multiple autoplay video panels are managed with React state and IntersectionObserver, loading lazily and transitioning in sequence as the user scrolls through the bento grid layout.
04
3D Tilt Mouse Interaction
Cards respond to mouse movement with a perspective tilt effect, calculated in real-time from cursor position relative to each element — adding depth without any external 3D library.
05
Fully Responsive Layout
All animations and layouts adapt gracefully from desktop to mobile. Animations are disabled or simplified on reduced-motion preferences.
