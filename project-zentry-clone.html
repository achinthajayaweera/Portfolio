ABOUT
THE PROJECT

Zentry is a next-generation gaming and metaverse platform built around the concept of a unified "Play Economy" — a shared cross-world identity layer that connects players across every game, platform, and reality. Their website is one of the most technically ambitious gaming landing pages on the internet, combining cinematic scroll animations, multi-layer video compositing, physics-driven interactions, and a deeply custom scroll architecture into a single seamless experience.

This project is a full recreation of that website — rebuilt entirely from scratch using React 18, TypeScript, Vite, GSAP, Tailwind CSS, and Locomotive Scroll. Every scroll-driven animation, every video interaction, every polygon clip-path transition, every GSAP timeline was reverse-engineered, understood, and reconstructed by hand. Nothing was copied. Everything was rebuilt.

The result is a production-grade frontend application that matches the visual fidelity, interaction depth, and animation precision of the original — demonstrating advanced command of modern animation architecture, scroll-driven UI systems, and premium interactive web experiences.

WHY THIS
CLONE

Recreating a website of this calibre is one of the most rigorous self-imposed challenges a frontend developer can take on. This is not a standard marketing page or a component library demo. It is a fully choreographed interactive experience where every section has its own animation system, its own scroll logic, and its own set of composited layers that must work together precisely or the illusion collapses entirely.

The decision to clone Zentry specifically was deliberate. The website uses scroll-driven clip-path morphing, multi-layer video stacking with GSAP-controlled z-index, mouse-position-aware cursor reveal systems, polygon-masked images with SVG gooey filters, scroll-pinned sections with cumulative animation offsets, and a smooth scroll engine that keeps GSAP's ScrollTrigger and Locomotive Scroll in perfect sync.

Building this forced a granular understanding of how world-class creative studios approach frontend architecture — not just what they build but why every technical decision was made the way it was, and what problems each system is solving.

Architecture Deep Dive
01
Smooth Scroll Architecture — Locomotive + GSAP Sync
Locomotive Scroll intercepts native scroll events and replaces them with lerp-interpolated position updates, creating the characteristic cinematic momentum. The useLocoScroll hook sets up a two-way synchronisation bridge with GSAP's ScrollTrigger via ScrollTrigger.scrollerProxy() — telling GSAP's entire animation engine to read scroll position from Locomotive's internal state rather than window.scrollY. SmoothScrollProvider wraps this in a React context, exposing the scroll instance and real-time progress to every component in the tree with zero redundant scroll handlers.
02
Hero — Multi-Layer Video System with Cursor Reveal
The Hero manages four simultaneous interactive systems. Four looping video elements are absolutely stacked inside #video-frame, with GSAP controlling their z-index to bring the correct video forward. On click, handleMiniVideoClick() animates the video's clipPath from a small polygon to full viewport over one second. The cursor reveal creates a cinematic torch effect — on every mousemove, a 200×200px polygon is computed from cursor position and applied to the background video's clipPath with 0.2s easing, making the reveal square chase the cursor with slight lag. After one second of inactivity, the background video fades invisible.
03
AboutUs — Scroll-Pinned Clip-Path Morphing
The About section starts as a small angled polygon shape centred on the page. A ScrollTrigger with pin: true and scrub: 0.5 locks the section for 800px of scroll. As scroll progresses, the onUpdate callback fires on every frame, using gsap.utils.interpolate() to move all four corner coordinates from their angled starting positions toward a perfect rectangle — while the image simultaneously scales from 30vw to full viewport. A MouseParallaxContainer adds a subtle mouse-tracking depth effect on desktop, giving the entire section a tactile quality.
04
AnimatedTitle — 3D Word Stagger System
The most reused component in the codebase, appearing across six sections. Each title string is split by <br/> tags into lines, then each line split into individual word spans. Every word starts at transform: translate3d(10px, 51px, -60px) rotateY(60deg) rotateX(-40deg) with transform-origin: 50% 50% -150px and perspective: 600px — pushed back in 3D space. A GSAP timeline stagger-animates all spans forward to translate3d(0,0,0) with stagger: 0.05, making each word fly forward and flatten out sequentially — producing the signature Zentry title animation.
05
Features Grid — BentoCard with 3D Mouse Tilt
BentoTilt calculates cursor position relative to each card using getBoundingClientRect(), normalises it to 0–1, and maps it to ±7.5° tilt angles. The transform is applied as perspective(700px) rotateX() rotateY() scale3d(.95,.95,.95) — pulling the card toward the user at its centre and away at its edges. On mouseLeave the transform resets cleanly. The grid assembles six cards in a responsive bento layout — from a full-width hero card for Radiant to two-column cards for Zigma, Nexus, Azul, and accent cards with oversized icon details at scale-[5].
06
Story Section — Gooey SVG Filter + Mouse Tilt + Parallax
Three independent interactions layered on one component. The mouse-tilt system maps cursor offset to ±25° on both axes via GSAP. The scroll parallax drifts the inner image at y: 100 slower than page scroll, creating depth separation. RoundedCorners injects an invisible SVG filter (feGaussianBlur → feColorMatrix → feComposite) that the image container references via filter: url("#flt_tag") — the gooey filter technique that makes the polygon clip look liquid rather than geometric.
07
Pinned Section — Sequential Scroll with Cumulative Offsets
The entire section is pinned for 4000px of scroll via ScrollTrigger with pin: true, pinSpacing: true. Three pagination items animate sequentially — each gets its own ScrollTrigger with a start offset that increments by 1000 per item (cumulativeOffset += animationDuration), so they fire one after the other through the pinned space. Each item runs two independent animations: a scrub-driven line that travels upward inside its container track, and a snap-in entry that expands the container height, brightens the title, and scales the description in from scaleY: 0.
08
NavBar — Scroll-Aware with Audio Visualiser
The scroll visibility system reads progress from useSmoothScroll() and compares to lastScrollY on every frame. Scrolling down triggers a GSAP y: -100, opacity: 0 slide-off. Scrolling back up triggers a return and adds the floating-nav class — transforming the navbar into a floating pill with black background and rounded corners. The audio system plays /audio/loop.mp3 via a hidden <audio> ref, and four indicator bars receive the active class to trigger a staggered CSS keyframe oscillation — the characteristic music visualiser effect.

react-icons

Key Achievements
01
Full Recreation of a Premium Gaming Landing Page
Every section, interaction, and animation system was reverse-engineered and rebuilt from scratch — matching the visual fidelity and interaction depth of an Awwwards-winning production site.
02
Multi-Layer Video System with GSAP Z-Index Control
Four stacked video elements managed by GSAP z-index, with a clip-path expand animation on click that morphs from a small polygon to full viewport in one second — restarting the video from frame zero each time.
03
Locomotive Scroll + GSAP ScrollTrigger Two-Way Sync
A scrollerProxy() bridge keeps Locomotive's interpolated position and GSAP's animation engine in perfect sync — ensuring every scroll-triggered animation fires at the correct position rather than being offset by the smooth scroll layer.
04
Scroll-Driven Polygon Clip-Path Morphing
An angled polygon shape morphs to a full-viewport rectangle as the user scrolls through the About section — pinned for 800px with scrub: 0.5 and per-frame gsap.utils.interpolate() on all four corner coordinates simultaneously.
05
Mouse-Position Cursor Reveal with Inactivity Timeout
A 200×200px polygon tracks the cursor position on every mousemove and applies it to the hero video's clipPath with constrained range and power2.out easing — creating a cinematic torch effect that fades after one second of inactivity.
06
3D Word Stagger Animation System Across Six Sections
Each title word starts at translate3d(10px, 51px, -60px) rotateY(60deg) rotateX(-40deg) and flies forward on scroll with stagger: 0.05 — a single reusable AnimatedTitle component powering the signature Zentry type animation across every major section.
07
Mouse Tilt on BentoCard Grid and Story Section
BentoTilt calculates real-time cursor offset from each card's bounding rect and maps it to ±7.5° perspective tilt. The Story section image tilts independently at ±25° with a smooth settle on mouseLeave — both implemented without any external 3D library.
08
SVG Gooey Filter for Organic Polygon Edge Rounding
An invisible SVG filter chain (feGaussianBlur → feColorMatrix → feComposite) referenced via filter: url("#flt_tag") makes the Story section's polygon clip look liquid and organic rather than hard-edged — the gooey filter technique used by top creative studios.
09
Sequential Scroll Animation with Cumulative Offset Pinning
The Pinned section locks for 4000px of scroll while three items fire sequentially — each ScrollTrigger's start offset incremented by 1000 via cumulativeOffset += animationDuration, running independent scrub-line and snap-in entry animations per item.
10
12-Commit Version History with Structured Development Progression
Built across 12 staged commits — from Vite scaffold to final production assembly — with global systems before section components and scroll infrastructure before the animations that depend on it. Mirrors professional frontend development practice with architectural intent throughout.
