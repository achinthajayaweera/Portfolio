Model Architecture
01
Input Layer — 224 × 224 × 3 RGB Image
Uploaded images are resized to 224×224 pixels and normalized to the [0, 1] range before being passed into the model.
PIL · NumPy
02
MobileNetV2 Base — Frozen Feature Extractor
154-layer pretrained CNN from ImageNet. Depthwise separable convolutions extract rich visual features. All weights frozen — only the classification head is trained on plant disease data.
Transfer Learning · 2.2M frozen params
03
GlobalAveragePooling2D
Collapses the 7×7×1280 spatial feature map into a single 1280-dimensional vector — making it compact and classification-ready.
Output: (1280,)
04
Dropout(0.3)
Randomly zeroes 30% of neurons during training to prevent overfitting and improve generalization on unseen leaf images.
Regularization
05
Dense Output — 26 Classes · Softmax
Final layer with 26 neurons — one per disease class. Softmax activation converts raw logits into a probability distribution. Predicted class = argmax of the output vector.
~26,000 trainable params · Adam Optimizer

ABOUT
THE PROJECT

Plant Disease Detection is an AI-powered web application built to address one of agriculture's most pressing challenges — the early identification of plant diseases. According to the FAO, plant diseases account for approximately 20–40% of global crop losses every year. Early detection is critical, yet traditional diagnosis requires trained agronomists physically inspecting crops — expensive, slow, and inaccessible in remote regions.

This project delivers an automated solution: upload a photo of any plant leaf, and the deep learning model instantly classifies it across 26 disease categories with a confidence score. The application is built on transfer learning using MobileNetV2 — a lightweight CNN pretrained on ImageNet — making it both accurate and fast enough for real-time web deployment.

The model was trained on Google Colab using a T4 GPU on the New Plant Diseases Dataset from Kaggle — over 87,000 labeled images across 38 disease classes covering 14 crop species. Data augmentation including flipping, rotation, zooming, and translation was applied to improve generalization.

The entire ML lifecycle is covered — from data collection and preprocessing, through model architecture design, training, evaluation, and persistence — to full cloud deployment with a custom-designed UI on Streamlit Community Cloud, accessible to anyone with a browser.
