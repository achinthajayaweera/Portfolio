ABOUT
THE PROJECT

The JavaScript Image Filters App is a browser-based image editing tool built entirely from scratch using vanilla HTML, CSS, and JavaScript — with no external libraries or frameworks of any kind. The project demonstrates a solid command of the HTML5 Canvas API, real-time pixel manipulation, and responsive UI design through pure web standards.

Users can upload any image from their device, which is rendered onto an HTML5 canvas element. JavaScript then reads the raw pixel data using getImageData(), applies filter transformations directly to the RGBA values, and writes the result back to the canvas using putImageData() — all in real time as the user adjusts the controls.

A hold-to-preview button lets users compare the filtered version against the original at any time. Once satisfied, the edited image is exported directly from the canvas as a downloadable file — no server round-trip, no upload, no external processing.

The project was built across 20 staged commits, each representing a meaningful feature addition — from the initial file upload and canvas render, through each filter implementation, to the final responsive layout and download functionality.

Key Features
01
Real-Time Filter Application
Filters are applied instantly as the user adjusts controls — pixel data is read from the canvas, transformed mathematically, and written back on every interaction with no perceptible delay.
02
Multiple Filter Modes
Supports a range of filter effects including brightness, contrast, saturation, grayscale, sepia, invert, and blur — each implemented as a direct mathematical transformation on RGBA pixel values.
03
Hold-to-Preview Original
A dedicated button lets users hold to temporarily reveal the original unfiltered image for side-by-side comparison, then instantly returns to the filtered view on release.
04
Upload Any Image
Accepts any image format supported by the browser via a file input — the image is drawn to the canvas and immediately ready for filter application.
05
One-Click Download
The edited image is exported directly from the canvas as a downloadable PNG — no server required, everything happens locally in the browser.
06
Zero Dependencies
Pure HTML, CSS, and JavaScript — no frameworks, no libraries, no build tools. Everything is implemented from first principles using native browser APIs.
Tech Stack
HTML5
Canvas element for image rendering and pixel access — file input for image upload.
CSS3
Responsive layout, filter controls UI, and cross-device styling — no frameworks.
JavaScript ES6
All filter logic, event handling, file reading, and canvas operations — pure vanilla JS.
Canvas API
getImageData / putImageData for direct RGBA pixel manipulation — the core of every filter effect.
File API
FileReader for loading user images and Blob/download for exporting the edited result.
GitHub Pages
Static hosting — deployed directly from the main branch, live with one push.
