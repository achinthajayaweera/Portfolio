ABOUT
THE DESIGN

The MediFind App UI is the complete mobile interface design for the MediFind healthcare platform — a smart prescription processing and pharmacy locator system developed as the SDGP project at the Informatics Institute of Technology by Group SE19.

The design covers both the patient-facing experience and the pharmacy management interface — from the initial onboarding and authentication screens through prescription upload, pharmacy discovery, seat selection, payment, and booking confirmation. Every screen was designed with a clear visual hierarchy, accessibility-first colour choices, and a consistent design language across the entire app.

The colour system centres on MediFind's signature blue and teal palette — communicating trust, cleanliness, and healthcare reliability. The typography uses a clean sans-serif system with strong weight contrast between headings and body text, ensuring readability across all screen sizes and lighting conditions.

The design file includes a full logo redesign suite — multiple iterations of the MediFind brand mark explored during development — along with component libraries, icon sets, and a complete interactive prototype demonstrating the user flow from sign-in to booking confirmation.

Design System
Colour Palette
Brand Colours

Typography
